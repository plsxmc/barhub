# BarHub

> 菜单栏图标收纳管理 —— 让 macOS 菜单栏回归清爽
> 原生 Swift、零第三方依赖、离线可用

## 功能特性

- **图标收纳**：把不常用图标收进面板，一键展开 / 收起
- **隐藏干扰**：需要时即刻唤出，不需要时彻底隐身
- **刘海屏适配**：为刘海屏 Mac 优化的菜单栏空间管理
- **生态联动**：与闪截 / FNKit 握手共存，互不打架
- **轻量**：常驻内存约 25 MB，空闲 CPU ≈ 0.3%

## 系统要求

- macOS 13+ · Apple Silicon（arm64 原生）
- 需要授权「辅助功能」（系统设置 → 隐私与安全性 → 辅助功能）
